3. KẾT QUẢ THỰC HIỆN TỪNG BƯỚC

[BƯỚC 1: DOCKER IMAGE — BUILD & TỐI ƯU MULTI-STAGE]
- Tạo ứng dụng Node.js Express (`app/package.json`, `app/server.js`) chạy trên cổng 3000
  với 2 endpoints: `GET /` và `GET /health`.
- Viết `Dockerfile` multi-stage build (Stage 1: `node:18-alpine` cài `npm install --production`,
  Stage 2: `node:18-alpine` copy `node_modules` + source, chạy dưới non-root user `appuser` UID 1001,
  tích hợp `HEALTHCHECK`).
- So sánh kích thước thực tế qua `docker images devops-lab8-app`:
  + `devops-lab8-app:1.0` (multi-stage):     186MB (content size 45.6MB)
  + `devops-lab8-app:fat` (non-multi-stage): 196MB (content size 47.4MB)
- Chạy container `lab8-app` và kiểm tra `curl http://localhost:3000/` & `/health` trả về JSON 200 OK.

[BƯỚC 2: DOCKER COMPOSE — MULTI-CONTAINER APP]
- Cấu hình `docker-compose.yml` + `nginx.conf` gồm 3 services trong bridge network `app-network`:
  + `app` (`lab8-app`, port `3000:3000`, trạng thái `healthy`)
  + `redis` (`lab8-redis`, `redis:7-alpine`, port `6379:6379`, volume `redis-data`)
  + `nginx` (`lab8-nginx`, `nginx:alpine`, port `80:80`, `depends_on` app `service_healthy`)
- Kiểm tra `docker compose ps` cả 3 containers chạy ổn định; `curl http://localhost/` và
  `curl http://localhost/health` qua Nginx reverse proxy hoạt động thành công.

[BƯỚC 3: PUSH & VERIFY IMAGE TRÊN SONATYPE NEXUS DOCKER REGISTRY (MỞ RỘNG #4)]
- Thay thế Docker Hub bằng **Sonatype Nexus Docker Hosted Registry** (`lab7-nexus`, cổng `8082`,
  repo `docker-hosted`, bật realm `DockerToken`):
  + `docker login localhost:8082` thành công
  + `docker push localhost:8082/devops-lab8-app:1.0` & `:latest` thành công
  + Kiểm tra Nexus REST API `/service/rest/v1/components?repository=docker-hosted` xác nhận lưu trữ
    đầy đủ các tags (`1.0`, `4`, `latest`) trên Nexus
  + Xóa ảnh local và `docker pull localhost:8082/devops-lab8-app:1.0`, chạy container `lab8-test-pull`
    trên cổng `3001` kiểm tra `curl http://localhost:3001/` thành công.

[BƯỚC 4: JENKINS CD PIPELINE — TỰ ĐỘNG DEPLOY]
- Dùng lại container `lab7-jenkins` (`http://localhost:8080`), cài đặt `docker-ce-cli` trong container
  và phân quyền `/var/run/docker.sock` (`chmod 666`), xác nhận `docker exec lab7-jenkins docker ps` OK.
- Thêm credential `nexus-docker-credentials` trong Jenkins và tạo job `DevOps-Lab8-CD-Pipeline`
  sử dụng `Pipeline script from SCM` đọc `Jenkinsfile`.
- Thực thi Build #4 thành công (`SUCCESS`, tổng thời gian 15,524 ms) qua đủ 6 stages:
  1. `Checkout`         : Clone source từ Git SCM (commit `9d08c20`)
  2. `Docker Build`     : Build `localhost:8082/devops-lab8-app:4` và `:latest`
  3. `Docker Scan`      : Chạy `docker scout quickview` (skip an toàn nếu không có Scout plugin)
  4. `Push to Registry` : `docker login localhost:8082` + push tag `:4` và `:latest` lên Nexus
  5. `Deploy Container` : Dừng container cũ và chạy `lab8-cd-production` trên cổng `3002:3000`
  6. `Verify Deploy`    : Kiểm tra `http://host.docker.internal:3002/health` và `/` -> 200 OK.

[BƯỚC 5: CI (BÀI 7) + CD (BÀI 8) — PIPELINE HOÀN CHỈNH]

- Cung cấp mẫu `Jenkinsfile.cicd` kết hợp Maven CI (`compile`, `test`, `package`) + Docker CD (`build`, `push`, `deploy`).
